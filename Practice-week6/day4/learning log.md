# Week 6 Day 4 — React Component Lifecycle

## Topics Covered
- React component lifecycle: mounting, updating, unmounting.
- Class lifecycle methods:
  - componentDidMount()
  - componentDidUpdate()
  - componentWillUnmount()
- Functional components and useEffect.
- Dependency arrays and cleanup functions.

## Key Learnings
- Mounting occurs when a component appears.
- Updating occurs when component props or state change.
- Unmounting occurs when a component is removed.
- useEffect supports side effects and cleanup in functional components.
- Dependency arrays control when effects re-run.
